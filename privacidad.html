Política de privacidad

CRP Medios y Entretenimiento S.A.C. (en adelante, "CRP") utiliza aplicaciones internas de análisis de datos para obtener las estadísticas de sus propias cuentas y canales en plataformas digitales (YouTube, Meta y TikTok). Esta política describe qué información tratan estas aplicaciones y con qué fin.

1. Alcance

Las aplicaciones son de uso exclusivo de CRP. Solo acceden a cuentas, páginas y canales que pertenecen a CRP o que CRP administra, y únicamente con la autorización expresa de quien administra cada cuenta.

2. Información que se obtiene

  • Datos públicos y de rendimiento de las publicaciones, videos y transmisiones de las cuentas de CRP (por ejemplo: vistas, tiempo de visualización, interacciones, suscriptores).
  • Reportes estadísticos agregados que ofrecen las plataformas (por ejemplo: audiencia por edad, género o país, fuentes de tráfico e ingresos estimados de las propias cuentas).

Los accesos son de solo lectura. Las aplicaciones no publican, modifican ni eliminan contenido, y no envían mensajes. No se obtienen datos personales individuales de los usuarios que ven o interactúan con el contenido: las estadísticas de audiencia son agregadas y anónimas.

3. Uso de la información

La información se usa solo para la medición interna del desempeño del contenido de CRP y la elaboración de reportes internos. No se vende, no se cede a terceros y no se usa con fines publicitarios fuera de CRP.

4. Almacenamiento y seguridad

La información se almacena en la plataforma de datos interna de CRP, con acceso restringido al personal autorizado. Las credenciales de acceso se guardan en un almacén de secretos protegido y nunca se comparten.

5. Conservación

Los datos estadísticos se conservan mientras sean necesarios para el análisis histórico del desempeño del contenido de CRP.

6. Revocación del acceso

Quien administre una cuenta puede revocar en cualquier momento el acceso de estas aplicaciones desde la configuración de seguridad de su cuenta en cada plataforma (por ejemplo, en Google: Cuenta de Google → Seguridad → Conexiones con terceros). El uso de datos obtenidos de las API de Google se ajusta a la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

7. Contacto

Para consultas sobre esta política: datascience@crp.pe (Área de Data y Monetización Digital).
